# One-time user steps (minimal)

1. Install Blender from https://www.blender.org/download/
2. Open terminal at project root.
3. Run:
   blender --background --python pet-kit/blender-scripts/batch_colorize_moods.py
4. Done. Colored mood files will overwrite in pet-kit/exports.

Optional animation (manual in Mixamo):
- Upload each mood file and apply one idle animation.
- Re-export GLB/FBX and finalize in Blender.
